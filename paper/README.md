# R2O / Process fidelity — SLM-Agents @ NeurIPS 2026 workshop submission

## Layout (single source of truth)
- `main.tex` — front matter + main text (6 content pages). Ends with `\input{appendices}` and `\input{checklist}`.
- `appendices.tex` — all appendices. Tables are **not** inlined: each is `\input{tab_*.tex}`.
- `tab_*.tex` — GENERATED by `python analysis/build_tables.py` (captions live in `analysis/table_captions.json`).
  Do not hand-edit; edit the caption JSON or the source CSVs and regenerate.
  `tab_landscape.tex` is the one hand-maintained table (48 rows; the gate checks its Dep./CL columns
  against `analysis/metric_landscape.csv` and that every `\citet` key exists in `refs.bib`).
- `checklist.tex` — NeurIPS paper checklist (required in the PDF by the workshop CFP).
- `refs.bib`, `neurips_2026.sty` (unmodified official style; see provenance note in main.tex).
- `fig*.pdf` — GENERATED by `python analysis/make_figures.py`, drawn at the size they are placed
  (fig1/fig2: 0.48\textwidth = 2.64 in; figA: \linewidth = 5.5 in) so on-page type is 6-7.5 pt.
  Changing the `\includegraphics` width without changing FIG_W/FIG3_W rescales the type; the gate checks this.
- `analysis/` — `verified_stats.json` (recomputed from raw score CSVs by `recompute_stats.py`),
  `build_tables.py`, `verify_paper.py` (gate), `matched_horizon_8b.{py,csv}`, `synthetic_invariance_check.{py,csv}`,
  `metric_landscape.csv`, `cells_main.csv`, `slm_*.csv/json`.
- `src/precheck`, `src/erep`, `src/docs` — the score CSVs / reports the gate and table builder read.

## Build
    pdflatex main && bibtex main && pdflatex main && pdflatex main

## Gate (run before every commit; must print GATE PASS)
    cd analysis && PAPER_DEANON_STRINGS="<surname1>,<surname2>,<affiliation>,<username>" python verify_paper.py
(`PAPER_DEANON_STRINGS` holds the author/affiliation strings the gate must not find; it is deliberately not in the repo so the shipped supplement stays anonymous.)
The gate (i) regenerates every `tab_*.tex` and byte-compares, (ii) pins every number printed in the prose
to `verified_stats.json` / the score CSVs (whitespace-insensitive but wording-pinned: if you rephrase a
sentence carrying a number, re-pin it in the gate deliberately), (iii) checks all citations resolve,
(iv) checks the landscape table against `metric_landscape.csv`, (v) forbids stale/de-anonymising strings,
(vi) checks the checklist's `\ref`s resolve and has no `\answerTODO`.
